Here are some of the git commands


Pulling down updated
•	git fetch - checks remote branch for updates
•	git status - shows if there are any updates and what files might conflict
•	git pull - pull updates from remote

Pushing updates to remote server
•	git fetch - checks remote branch for updates
•	git status - shows if there are any updates and what files might conflict
•	git add * - stage all new files and update for commit
•	git commit - creates new commit with staged files and changes
•	git push - pushes new commit to remote server
